1. Agent vs. Chatbot vs. Workflow

    Chatbot: Just talks. Answers one message at a time based only on what’s in the chat. Can’t use tools or take actions.

    Workflow: A fixed, step-by-step pipeline built by a human. The AI fills in text, but the steps never change.

    Agent: An AI that decides its own steps. It picks which tools to use, in what order, and when the job is finished.

    What makes it "agentic": It acts on its own, uses external tools, plans multi-step tasks, and fixes its own mistakes without needing you to guide it.

2. The ReAct Pattern
The agent works in a continuous loop:

    Reason: Think about what to do next.

    Act: Call a tool.

    Observe: Read the tool's result.

    Repeat until it has the final answer to give you.

3. When an Agent Is Overkill
Don't use an agent for simple, predictable tasks like summarizing text or looking up a single fixed stat. A plain prompt or standard script is faster, cheaper, and won't get confused. Only use an agent when you can't predict the steps in advance.

4. Tool Schemas Used

    4 Tools: Calculator, weather lookup, text file reader, and a scratchpad writer.

    Tool Descriptions Matter: The AI only knows how to use a tool based on its written description. Clear, specific descriptions prevent the AI from passing bad data or picking the wrong tool.

5. Conversation Memory vs. Working Memory

    Conversation Memory: The full, automatic chat history. It grows bigger with every turn.

    Working Memory: A deliberate scratchpad where the agent saves key facts. It stays short and clean even if the main chat history gets deleted or trimmed.

6. Common Failures & Quick Fixes

    Endless Looping: Set a hard limit on the total number of turns allowed.

    Inventing Tools/Wrong Arguments: Catch errors cleanly, sanitize inputs (like cleaning up text), and return a clear error message so the AI can try again.

    Tool Crashes: Wrap tool code in try/except blocks so an error returns helpful text instead of crashing the program.

    Unsupported Options: Make the tool return helpful hint messages (e.g., "City not found. Allowed cities: X, Y, Z").

7. Why Frameworks Exist
Building an agent from scratch requires writing a lot of repetitive code for loops, error handling, and history management. Frameworks like LangChain, LangGraph, or CrewAI bundle these core pieces together so you can build faster, handle multiple agents, and trace bugs without reinventing the wheel every time.
